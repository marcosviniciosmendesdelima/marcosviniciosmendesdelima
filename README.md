### 💻 Desenvolvimento Técnico: Help Desk Pro

Projeto focado em infraestrutura e lógica Back-end, onde aplico:

- **Core do Sistema:** Lógica de negócio desenvolvida em **Python**, com foco em performance e escalabilidade.
- **Padrões de Projeto:** Arquitetura baseada em **Clean Architecture** e **DDD** para máxima manutenibilidade.
- **DevOps:** Containerização completa via **Docker** e orquestração com **Docker Compose**.
- **Persistência e Fluxo:** Gerenciamento de Migrations, Gateways e modelagem via diagramas **UML**.
